# magisk-modules

Magisk / KernelSU 模块发布仓库。

本仓库用于发布各类 Magisk 与 KernelSU 模块。模块种类较多、用途各异，因此这里不统一描述具体模块的细节——**每个模块请以各自目录内的 README 和 Releases 页面的说明为准**。

> 说明：仓库本身仅作"模块分发"用途，方便统一管理、发布与回退版本。

---

## 目录结构

```
magisk-modules/
├── <module-a>/            # 模块 A 的项目文件与说明
├── <module-b>/            # 模块 B 的项目文件与说明
└── README.md              # 本文件（仓库级通用说明）
```

约定：
- 每个模块独占一个子目录，互不影响。
- 模块发布时以 `.zip` 形式打包，上传到对应 Releases。

---

## 如何安装一个模块

请先到对应模块的目录或 Releases 页确认它的用途和适配情况，再按下面通用流程安装。

### 方式一：从本地安装（推荐）

1. 下载模块的 `.zip` 包（不要解压）。
2. 打开对应管理器：
   - **Magisk**：App 首页 →「模块」→「从本地安装」，选择下载的 zip。
   - **KernelSU**：App →「模块」→「从本地安装」，选择下载的 zip。
3. 按提示重启，或等待模块生效。

### 方式二：手动解压

若模块被要求手动放置，一般解压后放入对应目录（例如 Magisk 模块目录 `/data/adb/modules/<模块名>/`），再重启设备使模块脚本生效。

> 具体路径与生效方式以各模块的说明为准。

## 发布规范（维护者）

给本仓库新增模块时请遵循以下约定：

1. 模块内容放在独立子目录，不与其它模块混放。
2. 每个模块至少附带一个 `README` 说明用途、适配设备/内核、安装方法与已知问题。
3. 发布时打 `.zip` 包，并建立对应 Release 以便版本回溯。
4. 若模块需要特殊配置（如开机自启、挂载、权限），在模块说明中单独写清。
