# magisk-modules

Magisk / KernelSU 模块发布仓库。

本仓库用于发布各类 Magisk 与 KernelSU 模块。仓库本身不存放模块源码，**所有模块都以 Release 形式发布**，每个 Release 对应一个可刷入的 `zip` 包，正文里包含该模块的功能说明、安装方法与注意事项。

---

## 快速开始

1. 进入 **[Releases](../../releases)** 页面
2. 找到你要的模块（根据版本号判断是第几个工具，见下方「版本规则」）
3. 展开对应 Release，下载其中的 `zip` 附件（**不要解压**）
4. 在 Magisk 或 KernelSU 管理器中选择「从本地安装」
5. 重启手机，模块生效

---

## 版本规则

- **主版本号 = 第几个工具**：`v1` 为第一个工具，`v2` 为第二个工具，以此类推
- **次版本号 = 该工具的修复 / 升级次数**：`v1.1` 为第一个工具的第一次修复，`v2.2` 为第二个工具的第二次修复，以此类推

> 例如：`v3.0` 表示第三个工具首次发布；`v3.1` 表示第三个工具的第一次修复；`v3.5` 表示第三个工具的第五次修复或升级。

## 安装方法

### 方式一：Magisk 管理器（推荐）

1. 下载模块 `zip` 到手机（放入内部存储，避免放在云盘或压缩软件临时目录）
2. 打开 Magisk App → 底部「模块」
3. 点击「从本地安装」→ 选择下载的 `zip`
4. 安装成功后点击「重启」，或手动重启手机

### 方式二：KernelSU 管理器

1. 打开 KernelSU 管理器 → 「模块」
2. 点击「从本地安装」→ 选择 `zip`
3. 重启手机

### 方式三：手动安装（高级用户）

1. 将 `zip` 解压到 `/data/adb/modules/<模块名>/`（需 root 权限）
2. 确认目录权限为 755
3. 重启手机

---

## 安装之后

- 重启后可在管理器「模块」列表中看到已安装的模块及其状态（已启用 / 禁用）
- 部分模块开机自启，无需手动操作；部分模块提供额外的操作入口（如重启服务、停止服务等）
- 模块的具体行为以对应 Release 正文为准

---

## 更新 / 卸载

### 更新模块

- 直接安装新版 `zip` 覆盖旧版即可，管理器会替换模块文件
- 个别模块更新后需要再次重启才生效
- 若新版存在已知问题，可在 Releases 页面下载旧版本回退

### 卸载模块

- 在管理器「模块」列表中点击对应模块的卸载（垃圾桶图标）
- 或手动删除 `/data/adb/modules/<模块名>/` 目录后重启

## 常见问题（FAQ）

**Q：下载的 zip 安装失败？**
A：确认文件已完整下载（对比 Release 页面标注的大小）；安装时选择的是 zip 本身而不是解压后的文件夹；尽量把 zip 放到手机内部存储再安装。

**Q：装完没有生效？**
A：绝大多数模块需要**重启手机**后才生效；重启后确认管理器中该模块状态为「已启用」，若被自动禁用请查看模块日志。

**Q：怎么知道某个版本对应哪个模块？**
A：看版本号主号即可：`v1` = 第一个工具，`v2` = 第二个工具……每个 Release 正文有详细说明。

**Q：可以同时安装多个模块吗？**
A：可以。仓库内不同工具相互独立，互不影响。

**Q：模块导致手机异常 / 变砖怎么办？**
A：开机进入 Magisk/KernelSU 的安全模式（禁用所有模块）后卸载问题模块；或使用 Recovery 手动删除 `/data/adb/modules/<模块名>/` 目录。

**Q：遇到问题如何反馈？**
A：在对应 Release 或仓库 Issues 反馈，尽量附上设备型号、系统版本、内核版本以及模块日志。

## 注意事项

- 刷入 Magisk / KernelSU 模块存在一定风险，可能导致系统异常、数据丢失甚至无法开机
- **操作前请务必做好数据备份**，并确认模块与你的设备、系统版本、内核版本兼容
- 本仓库模块仅供学习与技术交流使用，作者不对刷入后产生的任何损失负责
- 请勿将模块用于任何违法违规用途
